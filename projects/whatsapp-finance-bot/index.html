Automation / Personal Finance

WhatsApp Finance Bot

Asisten pencatatan finansial berbasis perintah percakapan dengan integrasi spreadsheet.

01 / Context

Masalah yang diselesaikan

Pencatatan transaksi manual mudah terlewat dan informasi cicilan tersebar, sehingga pengguna sulit memperoleh ringkasan keuangan dengan cepat.

Objective

Menyederhanakan pencatatan transaksi dan pencarian informasi finansial melalui pola interaksi yang familiar.

02 / Approach

Solusi dan proses bisnis

Bot menerjemahkan perintah singkat menjadi transaksi atau query terstruktur, lalu membaca dan menulis data pada spreadsheet.

PROCESS FLOW

Pengguna mengirim perintah, sistem memvalidasi intent dan nilai, data diproses, lalu bot mengembalikan konfirmasi atau ringkasan.

03 / System

Arsitektur dan fitur

WhatsApp interface → command parser → automation service → Google Sheets → formatted response.
